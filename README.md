# EvidenceTrust-Java

EvidenceTrust is a research framework for representation-aware
reliability in code classification, evaluated using Java
software vulnerability detection.

## Research architecture

- CodeBERT semantic vulnerability detector
- Joern CPG/GNN structural vulnerability detector
- Source-grounded representation diagnostics
- Calibration and conventional fusion baselines
- Diagnostic-aware EvidenceTrust fusion
- Selective human review
- Representation degradation and robustness evaluation

## Development environment

- Python source code: VS Code
- Version control: Git and GitHub
- Model training: Google Colab
- Datasets and checkpoints: Google Drive

## Dataset

MegaVul-Java (April 2024 release).

Large datasets and model checkpoints are not stored in this repository.
